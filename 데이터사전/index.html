    📚 데이터 사전¶

    생성 기준

    로컬 정본 schema.sql에서 39개 테이블과 컬럼을 기계 추출했다. 컬럼 추가·삭제는 python3 tools/generate_schema_dictionary.py로 다시 반영한다. PK·FK·CHECK의 최종 효력은 SQL 원문이 우선한다.

    읽는 법¶

    • 생산자는 행을 쓰는 JOB·컴포넌트, 주요 소비자는 그 행을 읽는 다음 단계다.
    • 선택은 NULL 허용이다. NULL이 결손인지 ‘해당 증거 없음’인지 테이블 설명과 함께 판단한다.
    • pipeline_*는 MVP 1차 호환 유물이며 최종 일일 실행 원장은 tb_job_run이다.
