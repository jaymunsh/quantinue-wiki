## 프로젝트 요약

Quantinue는 실물 시장 데이터와 AI 판단으로 움직이는 **모의 자동매매 관측 시스템**이다.
시세·뉴스·공시·거시 데이터와 LLM 판단은 실제 입력을 사용하지만, 주문은
`MockBroker`로만 체결된다. 실제 돈을 보내는 기능은 최종 범위에 없다.

1차에서 만든 판단 체인 위에 최종 프로젝트가 다음 두 층을 추가했다.

| 층 | 동작 | 현재 상태 |
|---|---|---|
| 일일 체인 | 외부 데이터 수집 → DB 선별 → 공격형·안전형 전략가 → Critic → 청산·배분 | 운영 중 |
| 장중 방어선 | 1분마다 보유 종목의 손절·익절선을 코드로 확인 | `watch=true` 운영 중 |
| 장중 사건 재판단 | ±5% 급변·SEC·뉴스 사건을 관련 종목에 라우팅하고 LLM 재호출 | 구현 완료, `rejudge=false` |
| 실시간 시세 스트림 | 보유 종목을 웹소켓으로 받고 폴링을 fallback으로 유지 | 구현 완료, `stream=false` |

핵심 원칙은 **AI가 판단하고, 코드는 제한하고, 원장이 이유를 보존한다**는 것이다.
손절·익절과 멱등성·예산·권한은 LLM 바깥의 결정론적 코드가 강제한다.

## 실제 관측 수치

2026-07-19~07-27의 7개 슬롯일 원장에는 다음이 남아 있다.

| 항목 | 실측 |
|---|---:|
| 판단 | 342건 (매수 266 · 보류 49 · 매도 27) |
| Critic 검토 | 323건 (통과 222 · 반려 57 · 보류 44) |
| 후보 | 222건 |
| 주문 = 체결 | 62건 (운용 27 · 회귀 검증 35) |
| 결정론 게이트 종료 | 271건 (83.9%) |
| 유료 LLM 호출 | 4일 312콜 · `$0.53` (일 상한 `$3`) |

이 수치는 수익률을 과장하기 위한 성과 지표가 아니라, **판단→반박→체결의 계보가
실제로 원장에 남았는지**를 보여주는 검증 수치다.

## 운영 상태와 남은 선택

구현이 끝났다는 것과 모든 비용이 드는 운영 기능을 켰다는 것은 구분한다.

| 항목 | 현재 |
|---|---|
| 일일 JOB 체인 | 운영 관측 중 |
| 1분 가격 방어선 | 켜짐 · LLM 0콜 |
| Telegram 일일 요약·실패 알림 | 켜짐 |
| Healthchecks 생존 신호 | 운영 설정 완료 |
| 사건 수집·정규화 | 구현·운영 경계에 포함 |
| 사건 기반 LLM 재판단 | `rejudge=false` — 다음 Gate B 검증 후 선택 |
| 웹소켓 시세 | `stream=false` — 폴링 fallback 유지 |
| AWS 이전 | 미착수·선택 사항 |

따라서 프로젝트의 개발·발표 산출물은 마무리됐고, 남은 것은 새 기능 개발이 아니라
재판단과 스트림을 언제 운영 활성화할지에 대한 **운영 의사결정**이다.
