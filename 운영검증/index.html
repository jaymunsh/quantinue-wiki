    📈 운영 검증과 한계¶

    최종 프로젝트 검증 기준 · 2026-07-28

    구현 완료 여부, 실제 운영 중인 범위, 아직 의도적으로 꺼 둔 범위를 분리해 기록한다. rejudge=false와 stream=false는 구현 여부가 아니라 선택 기능의 운영 검증 상태다.

    구현·검증 결과¶

    항목 결과
    애플리케이션 FastAPI·PostgreSQL 원장·관리자 관제실·사용자 계좌
    일일 운용 등록 JOB 14종·뉴욕 거래일 슬롯·멱등 실행
    장중 방어 1분 가격 감시·손절/익절·MockBroker 청산
    AI 판단 공격형·안전형 Strategist + Critic
    테스트 유닛·웹 804건 + 통합 190건 = 총 994건 green
    브로커 MockBroker만 사용 · 실제 주문 없음

    현재 운영 경계¶

    기능 상태 의미
    일일 JOB 체인 🟢 운영 중 수집→선별→판단→청산→배분
    1분 방어선 🟢 운영 중 LLM 0콜로 손절·익절 확인
    사건 수집·정규화 🟡 구현 완료·실측 부족 증분 경로는 있으나 운영 원장 사건 0건
    사건 기반 재판단 🟡 구현 완료·운영 검증 전 사건·±5% 급변 종목만 AI 재호출. 비용·중복 주문 검증 전이라 rejudge=false
    웹소켓 시세 ⚪ 선택 기능·운영 검증 전 최대 30종목 실시간 구독. 재연결·fallback 검증 전이라 stream=false, 1분 폴링 유지
    AWS 이전 ⚪ 미착수 로컬 운영 완료를 막지 않는 선택 사항

    해석의 한계¶

    • 이 수치는 수익률이나 실거래 성과가 아니라 시스템 실행·계보·비용 검증 수치다.
    • 시세·뉴스·공시는 실물 데이터를 사용하지만 체결은 모의다.
    • 장중 재판단은 코드와 강제 발동 테스트까지만 완료됐고 실제 기능일 운영 기록은 없다.
    • 웹소켓은 반응 속도를 높이는 선택 기능이다. 현재 손절·익절 방어는 1분 폴링이 담당한다.
    • 실제 운영 전환은 운영 가이드의 단계별 Gate 절차를 따른다.
